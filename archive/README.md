# Archived puzzle pages

Copies of the creator's pages, kept because gsmg.io was offline for part of 2026. The bytes are as
captured; they were collected in [AppleLamps/combined-puzzle](https://github.com/AppleLamps/combined-puzzle)
(`GSMG-CLEAN/originals/`), where the same files appear byte for byte in three separate research repositories.

| file | original URL | source |
| --- | --- | --- |
| [pages/theseedisplanted.html](./pages/theseedisplanted.html) | `https://gsmg.io/theseedisplanted` (phase 1) | Wayback capture `20201112021936`, saved with its Wayback markup; the `<img>` paths point to `../images/rebus/` so the page renders offline |
| [pages/phase2_choice.html](./pages/phase2_choice.html) | `https://gsmg.io/choiceisanillusion...iwroteitmyself` (phase 2, holds the phase 2 and phase 3 envelopes) | saved page |
| [pages/salphaseion_phase3.html](./pages/salphaseion_phase3.html) | `https://gsmg.io/89727c598b9cd1cf8873f27cb7057f050645ddb6a7a157a110239ac0152f6a32` (SalPhaseIon and Cosmic Duality) | matches the Wayback capture [20230601222752](https://web.archive.org/web/20230601222752/https://gsmg.io/89727c598b9cd1cf8873f27cb7057f050645ddb6a7a157a110239ac0152f6a32) |
| [images/poster/follow_the_white_rabbit.png](./images/poster/follow_the_white_rabbit.png) | `https://gsmg.io/img/follow_the_white_rabbit.png` | the poster grid as served (350x350); reported byte-identical in Wayback captures of 2020-11-15, 2024-04-06 and 2026-01-03 |
| [images/rebus/](./images/rebus/) | the eight tiles of the phase 1 page | from the 2020-11-12 capture |

The phase 1 tiles pair up as CA+N YOU, DIG I+T, LO+GIC and WAR+NING ("Can you dig it", "Logic", "Warning"). The
red `crypto` tile is a distractor.

With whitespace removed, the two textareas of `salphaseion_phase3.html` are identical to
[../unverified/gsmg-puzzle-kit/salphaseion-textarea.txt](../unverified/gsmg-puzzle-kit/salphaseion-textarea.txt) and
[../unverified/gsmg-puzzle-kit/cosmic-duality.b64](../unverified/gsmg-puzzle-kit/cosmic-duality.b64).

The poster page itself (`https://gsmg.io/puzzle`) is in the
[2020-11-09 capture](https://web.archive.org/web/20201109085204/https://gsmg.io/Puzzle).
